Page/section: Save a workbook in another file format; File formats that Excel supports — Other file formats

Most of the time, you probably want to save your workbook in the current file format (.xlsx). But sometimes, you might need to save a workbook in another file format, like the file format of an earlier version of Excel, a text file, or a PDF or XPS file.

PDF .pdf Portable Document Format (PDF). This file format preserves document formatting and enables file sharing. When the PDF format file is viewed online or printed, it retains the format that you intended.
